To generate a project, you create beans of type api:projectgen.core.feature.Feature[].
Each feature has a unique identifier; you can offer a https://launch.micronaut.io[UI] to allow users to select a feature.

Moreover, you can create beans of type api:projectgen.core.feature.DefaultFeature[] to be
automatically applied if the method `DefaultFeature::shouldApply` evalutes to true.
